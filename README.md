# Credit Card Dashboard UI (v0)

Este repositorio contiene una implementación de un Dashboard de Tarjetas de Crédito utilizando Next.js, Tailwind CSS (v4) y TypeScript, replicando la versión v0 del proyecto.

> **Nota:**  
> Se han incluido instrucciones para evitar problemas conocidos, como conflictos de dependencias y errores relacionados con la configuración de Tailwind en el archivo `globals.css`.

## Prerrequisitos

- **Node.js:** Recomendada la versión 14.x o superior.  
- **npm:** Preferiblemente versión 6 o superior.
  
> Si encuentras conflictos de dependencias, se recomienda utilizar el flag `--legacy-peer-deps` al ejecutar la instalación.


### 1. Clonar el Repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/CamiloToroUCC/taller-IA-dise-o.git
```

### 2.Instalar Dependenci


```bash
npm install --legacy-peer-deps
```


### 3. Ejecuta

```bash
npm run dev
```
